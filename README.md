This project moved from [SourceForge](https://sourceforge.net/projects/treeds4j/).

This API allows to fill n-ary tree data structure (which is a Directed Acyclic Graph) based on coherent in-memory input (text).

Since version 2.0, this API allows to load the tree from an SQL database (SQL Unary Relation).

Version 2.2 introduced unit testing enhancements with testcontainers, in addition to dependencies upgrade to eliminate CVEs.
